Sidecar Projects

A sidecar lets you use Foreman's structured workflow on projects you don't own — client codebases, open-source repos, or any directory where adding a docs/roles/ folder would be inappropriate.

The idea

Instead of putting role files inside the project, you keep them in a separate directory you control. Foreman reads roles from the sidecar but launches terminals pointed at the real project path.

Suggested layout

~/foreman-sidecars/
  their-repo/
    docs/
      roles/
        dev.md
        planning.md

How to set it up

In the Register Project dialog, set the Project path to the target repo and the optional Workflow path to your sidecar directory. If you leave Workflow path blank, Foreman behaves as normal (roles discovered from the project root).

Briefing difference

When a sidecar is configured the briefing distinguishes the two paths so Claude Code knows where to work and where the workflow docs live.
