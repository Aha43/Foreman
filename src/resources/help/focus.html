Focus

The Focus button appears on a session row when a terminal is already running for that project + role. Pressing it (or pressing F on a selected row) brings that terminal window to the front and activates Terminal.app.

How it works

Foreman records the TTY device of each terminal it opens. Focus uses AppleScript to find the Terminal.app window on that TTY and activate it. No new window is opened — you land exactly where you left off.

Stale sessions

If the terminal was closed since the last time Foreman checked, the row will flip back to Launch the next time Foreman's window gains focus. TTY numbers are recycled by the OS, so Foreman re-validates all sessions on window focus to avoid pointing at the wrong terminal.
