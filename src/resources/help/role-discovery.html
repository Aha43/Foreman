Role Discovery

When you register a project, Foreman scans docs/roles/*.md (non-recursive) and turns each file into a role in the shared library.

How a role name is derived

  1. If the first line of the file matches # Role: <name> or # <name>, that name is used.
  2. Otherwise the filename is used: .md is stripped, hyphens and underscores become spaces, and the result is title-cased.

Deduplication

Roles are shared across projects. If two projects both have a dev.md with the heading # Dev, Foreman creates one "Dev" role and assigns it to both teams. The first-registered version of the instructions wins.

Role instructions

The entire file content (markdown) becomes the role's instruction text. This is what Foreman includes in the briefing pasted into Claude Code on Launch.

Convention

<project-root>/
  docs/
    roles/
      planning.md
      dev.md
      dogfooding.md
