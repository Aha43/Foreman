Registering a Project

Click Register Project in the toolbar (or press ⌘R) to add a project to Foreman.

What happens

  1. A dialog asks for the project directory. Use Browse… or type the path directly.
  2. Foreman derives the project name from the directory name — you can edit it before confirming.
  3. Foreman scans docs/roles/*.md under that directory and registers any roles it finds.
  4. The project appears in the list and is selected immediately.

After registration

A message below the project list confirms how many roles were discovered. If no docs/roles/ directory exists the project is registered with an empty team — you can add role files later and re-register.

External projects

For projects you don't own (client repos, open-source), consider a sidecar workflow path so you don't inject Foreman files into foreign codebases.
