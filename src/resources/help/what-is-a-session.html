What Is a Session?

A session is one running instance of Claude Code for a specific project and role. If you have Foreman open with two projects each with three roles, you could have up to six sessions open simultaneously.

The problem sessions solve

Multiple unlabelled terminal tabs all running Claude Code look identical. Foreman solves this by opening each terminal itself, giving it a title, and tracking which terminal belongs to which project + role combination.

Session states

  • Stopped — no terminal window exists for this session. The row shows a Launch button.
  • Running — a terminal window is open. The row shows a Focus button.

State detection

Foreman tracks sessions by the terminal's TTY device (e.g. /dev/ttys004), assigned at launch. State is in-memory: if Foreman restarts, all sessions reset to Stopped even if the terminals are still open.
