Launch

The Launch button appears on a session row when no terminal is open for that project + role combination. Pressing it (or pressing L on a selected row):

  1. Opens a new Terminal.app window with the working directory set to the project path.
  2. Generates a briefing and copies it to the clipboard.
  3. Marks the session as Running in Foreman.

Paste immediately after Claude Code starts — the briefing is already on your clipboard.

macOS only

Launch uses AppleScript to open Terminal.app. On other platforms the button is not shown (the manual toggle is shown instead).

After launch

The button changes to Focus. Click it any time to bring that terminal window to the front without losing your place.
