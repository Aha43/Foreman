Getting Started

Foreman keeps track of which AI chat sessions are open across your projects, and makes it easy to launch each one in the right working directory with the right briefing.

First steps

  1. Click Register Project (or press ⌘R) and point Foreman at a project directory.
  2. Foreman scans docs/roles/ and adds any roles it finds to the shared library.
  3. Switch to the Sessions tab to see the project × role grid.
  4. Click Launch on a row to open a terminal, copy the briefing, and start a Claude Code session.
  5. Use Focus to jump back to a running session's terminal window at any time.

Key concepts

  • Registering a project — how Foreman learns about your codebase
  • Sessions — what a session is and how state is tracked
  • Briefings — what gets pasted into Claude Code on launch
