What's in a Briefing

A briefing is the text Foreman copies to your clipboard on Launch. Paste it into Claude Code immediately after startup to orient the session.

Structure

You are [Role label] for [Project name].

Your working directory: /path/to/project

Before starting, read:
  - /path/to/project/CLAUDE.md
  - /path/to/project/docs/roles/dev.md      (your role)
  - /path/to/project/docs/features/...      (design docs, if present)

Your task:
  - Closes #42 — Add dark mode toggle
  - Closes #43 — Fix settings persistence

Do not start until you have read the files listed above.

Role doc

The path to the role's source .md file is included so Claude Code can read the full instructions. If the file can't be found by path Foreman falls back to embedding the instructions inline.

Design docs

Foreman scans docs/features/ for design.md files and lists them. This helps Claude Code find feature-level context without being told explicitly.

GitHub issues

See GitHub issues integration for how open issues appear in the task list.
