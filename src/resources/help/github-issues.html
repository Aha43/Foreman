GitHub Issues Integration

Foreman can include open GitHub issues in the briefing's task list so Claude Code knows what to work on without you having to copy issue numbers manually.

How to use it

In the Brief dialog (or before Launch), select the issues you want to include. Foreman fetches open issues from the GitHub repository associated with the project and lists them as Closes #N — <title> entries in the briefing.

Repository detection

Foreman reads the .git/config remote URL from the project directory to find the GitHub repo. If no remote is configured the issues section is omitted.

Authentication

Public repositories work without authentication. For private repositories Foreman uses the token stored in the system keychain (same as the GitHub CLI).
