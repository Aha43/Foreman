Settings

Open Settings from the toolbar or press ⌘,.

Default project directory

The directory the Register Project file chooser opens to. Foreman updates this automatically to the parent of the last registered project, so it tends to stay in the right place without manual adjustment.

Dense mode

When enabled, toolbar and session panel buttons show icons only — no text labels. Useful on smaller screens or when you know the icons by heart.

Toggling the checkbox applies the change immediately so you can see the effect before clicking OK. Clicking Cancel reverts to the previous setting.

Persistence

Settings are saved to ~/.foreman/settings.json (production) or ~/.foreman/dev/settings.json (dev mode).
